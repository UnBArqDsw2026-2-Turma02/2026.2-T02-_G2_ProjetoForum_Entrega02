## Organização das reuniões

Cada subgrupo possui uma liderança própria, responsável por organizar as
conversas e repassar os encaminhamentos ao grupo geral. A coordenação geral
do projeto (liderança master) é exercida por **Pedro Felipe Silva Vargas**.

equipe toda) e **Reuniões por Subequipe** (internas de cada subgrupo). Cada
linha das tabelas abaixo aponta para a ata detalhada correspondente (ver
também o [Modelo de Ata](/Base/iniciativas_extras/atas_reuniao/modelo-ata.md)).
